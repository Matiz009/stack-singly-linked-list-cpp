# Stack Using a Singly Linked List (C++)

A stack built on a singly linked list in C++.

## Features

- `push`: adds a node on top
- `pop`: removes the top node and prints its value (prints "Stack is empty" if there is nothing to pop)
- `display`: prints every element in the stack

## Tech stack

C++

## Getting started

```bash
git clone https://github.com/Matiz009/stack-singly-linked-list-cpp.git
cd stack-singly-linked-list-cpp
g++ "code.cpp" -o code && ./code
```
